# Claude Code Project Instructions

This repository is developed collaboratively using multiple AI coding agents.

Before working on any implementation task, read:

1. `AGENTS.md` — canonical development and agent collaboration rules
2. `README.md` — project purpose and architecture
3. `ROADMAP.md` — planned project trajectory
4. `HANDOFF.md` — current implementation state and active slice

Treat `AGENTS.md` as the canonical collaboration contract and follow its
Builder, Teacher, and Reviewer modes. Do not continue to future roadmap items
automatically.

The repository and its version-controlled documentation are the source of
truth. Do not rely on Claude-specific memory for architectural decisions,
project state, evidence boundaries, or other knowledge another coding agent
would need later. Preserve important cross-agent knowledge in code, tests, git
history, or shared repository documentation.
